# gh-读书笔记：三层结构化笔记引擎

输入一段内容——视频字幕、电子书章节、文章、演讲记录——输出一份三层结构化的读书笔记：前端是抽到第一性原理的核心知识点，中间是落到地上的重点与案例，尾端是拉开距离的多维批判审视。

三层不是三段摘要。摘要是一遍过，三层是挖三次：第一次往下挖到根，第二次贴着地面走，第三次往后退看全景。

## 什么时候用

- 用户粘贴了一段视频字幕，说"帮我做笔记""总结一下""整理成读书笔记"
- 用户贴了电子书/文章内容，想萃取成结构化笔记
- 用户发了一个 B站/YouTube/课程 的文字稿
- 用户说 '读书笔记', '笔记', '提炼', '总结成笔记', 'reading notes'

## 三层结构总览

```
┌─────────────────────────────────────────────┐
│  第一层：第一性原理层（前端）                  │
│  ↓ 往下挖——这个东西最底层的逻辑是什么？        │
│  核心概念 → 底层机制 → 不可再分的骨架          │
├─────────────────────────────────────────────┤
│  第二层：重点与落地层（中间）                  │
│  ↓ 贴着地——有哪些要点？有哪些案例能直接用？    │
│  要点梳理 → 案例还原 → 行动清单                │
├─────────────────────────────────────────────┤
│  第三层：批判性审视层（尾端）                  │
│  ↓ 往后退——拉开距离，从多个角度审视这段内容    │
│  视角切换 → 盲点识别 → 适用边界                │
└─────────────────────────────────────────────┘
```

## 第一层：第一性原理层

### 这一层在做什么

把内容里的"是什么"拆到"为什么"——拆到不能再拆、不依赖任何行话也能成立的底层逻辑。第一性原理的意思是：如果从零开始重建这个知识，你只需要哪几块砖？

### 操作步骤

**Step 1: 找出核心概念**

从内容中挑出 3-5 个核心概念。每个概念用一句话定义——用自己的话，不用原文的行话。

挑概念的标准：删掉它，整段内容就塌了。不是"作者提到了什么"，是"作者依赖了什么"。

**Step 2: 找到底层机制**

问：这些概念之间怎么互相作用的？把机制画成一条因果链或反馈环：

```
[输入/条件] → [机制 A] → [中间状态] → [机制 B] → [结果]
```

这不是流程图，是因果图——每一步要能回答"为什么这一步导致了下一步"。

**Step 3: 提炼不可再分的骨架**

把整段内容压到 2-3 个第一性命题。每个命题的格式：

> **"如果不成立 A，则整件事不成立"**

或

> **"这件事的本质是 X，而 X = Y + Z"**

测试：一个完全没听过这个概念的人，看了这几个命题，能不能把整件事推导出来？能 → 骨架对了。不能 → 还没拆到底。

### 输出格式

```markdown
## 第一层：第一性原理

### 核心概念
**1. {概念名称}**
- 一句话定义：...
- 在内容中的角色：...

**2. {概念名称}**
- 一句话定义：...
- 在内容中的角色：...

...（3-5 个）

### 底层机制
[因果链或文字描述]

### 不可再分的骨架
1. **命题一：** ...
2. **命题二：** ...
3. **命题三：** ...
```

## 第二层：重点与落地层

### 这一层在做什么

第一层抽走了具体性，第二层把它还回来。从"知道了"到"能做到"——提取关键论点、还原案例、给出可执行的行动清单。

### 操作步骤

**Step 1: 梳理重点内容**

按逻辑线（不是原文顺序）组织重点。每条重点一行标题 + 2-3 句展开。

规则：
- 不照抄原文——用自己的话浓缩
- 每条重点之间要有逻辑关系（并列/递进/因果），不是散点
- 数据、对比、结论要保留，修饰性语言全砍掉

**Step 2: 还原/提取案例**

如果内容里有案例——完整还原，保持故事性：
- 背景（什么情况下发生的）
- 操作（具体做了什么）
- 结果（发生了什么变化）
- 可迁移点（这个案例里什么东西能挪到别的场景用）

如果内容里没有案例——从知识的逻辑推一个可落地的场景：在什么情况下，这个知识能用来做什么决策/解决什么问题。

**Step 3: 生成行动清单**

至少 3 条，每条格式：
- **做什么**（具体动作，不是方向）
- **什么时候做**（触发器/条件）
- **做到什么程度**（可验证的标准）

不能说"注意风险控制"——要说"当 X 指标超过 Y 值时，将 Z 仓位降至 W%"。行动清单的敌人是"可意会不可执行"。

### 输出格式

```markdown
## 第二层：重点与落地

### 重点内容
**1. {要点标题}**
...

**2. {要点标题}**
...

### 案例
**案例：{案例名}**
- 背景：...
- 操作：...
- 结果：...
- 可迁移点：...

### 行动清单
1. **{具体动作}** —— 触发条件：... | 验证标准：...
2. ...
3. ...
```

## 第三层：批判性审视层

### 这一层在做什么

从"信"到"疑"——拉开距离，从多个角度审视内容的优缺点、隐含假设、适用范围和没说的事。读书笔记不是复读机，是对话。这一层就是你在问内容："你说的对不对？在哪对？在哪不对？有什么你没说的？"

### 操作步骤：四维审视

**维度一：逻辑链审查**

沿着内容的核心论证画出一条逻辑链，逐个节点审查：
- 前提成立吗？有没有隐含假设？
- 从前提推到结论的每一步，有没有逻辑跳跃？
- 有没有把相关性当因果性？（这是最常见的逻辑漏洞）

输出：指出 1-3 个逻辑薄弱点。

**维度二：反身性检验**

翻过来看——把内容的结论倒过来问：
- 如果反过来做会怎样？
- 在什么条件下，这条建议是错的？
- 作者的结论是否依赖于特定的时间窗口/市场环境/样本？

输出：画出结论的适用边界。

**维度三：盲点与缺失**

一个好内容的盲点比它的亮点更需要被看见。问：
- 内容里最理所当然、问都没问的那件事是什么？
- 有没有重要的利益相关方/视角被略过了？
- 数据/案例有没有幸存者偏差的选择性？
- 作者的立场/利益会不会影响结论？

输出：列出 2-3 个明确盲点。每个盲点标注为什么它重要。

**维度四：对立视角**

找至少一个和内容核心结论对立或显著不同的立场/流派/观点。不是抬杠，是"同样的数据，有没有另一种解释"。如果有，说明那个立场和内容的差异在哪。

输出：至少一个对立视角 + 它的核心论点。

### 输出格式

```markdown
## 第三层：批判性审视

### 逻辑链审查
- **薄弱点 1：** ...
- **薄弱点 2：** ...

### 适用边界
- ✅ **成立条件：** ...
- ❌ **不适用场景：** ...

### 盲点与缺失
1. **盲点：{标题}** —— 为什么重要：...
2. **盲点：{标题}** —— 为什么重要：...

### 对立视角
**{对立流派/观点}** 认为：...
与内容的差异在于：...
```

## 怎么写

三层之间有一种递进关系，但每层内部是平面展开的。

**第一层要冷。** 不评价，不感叹，不"值得注意的是"。就是抽骨架——把肉的、软的全部剔掉。剩下那几根骨头，放哪本书里都能立住。概念定义要干净——"X = Y + Z" 比 "X 是一种..." 有力。

**第二层要实。** 案例要有时间有地点有数字，行动清单要可执行、可验证。不能出现"关注""重视""注意"这类动词——它们不是动作，是态度。行动清单的读者是一个不知道你是谁的人，他看了每一条，不需要任何额外解释就能执行。

**第三层要狠。** 不是找茬，是拉开距离。作者说的有道理，但道理有边界——把边界画出来。逻辑薄弱点、隐含假设、没说的事——不是贬低内容，是让它诚实。好内容的批判性审视会让内容更有用，因为你知道在哪有用、在哪没用。

**全篇禁用表格。** 笔记最终会粘贴到 flomo，flomo 不支持 markdown 表格渲染。所有对比、对照、盘点类内容，用层级结构：加粗标题 + 缩进列表项，每个列表项用 `---` 分隔。示例：

```
**概念 A** 
- 定义：... 
- 角色：...

**概念 B** 
- 定义：... 
- 角色：...

```

不是"[概念A | 定义 | 角色]"。数据对比如果超过两项，分行用"---"隔开，每行格式统一。

三层写完，默问三个问题：
1. 第一层的命题删掉任何一个，第二层的那堆要点还能不能推导出来？能 → 第一层没拆到底。
2. 第二层的行动清单换个人看，能不能照做？不能 → 还不够实。
3. 第三层的批判有没有一条是"我觉得不太对"但没有给出具体的逻辑、数据、或对立观点的？有 → 那条是感觉，不是批判，删掉。

## 反翻译腔自查

- **通过...的方式** → 直接动词
- **进行（研究/分析/讨论）** → 用具体动词
- **在...上/中/下** → 省掉或改写
- **值得注意的是** → 删掉——真值得注意不用说这句
- **作者认为/指出/论证了** → 直接说内容

默念一遍：读出声来，卡的地方整句重写。

## 红线

1. **三层必须完整。** 缺少任何一层 = 没做完。
2. **第一层的命题必须不可再拆。** "这件事要做好需要努力"不是第一性原理——"努力"还能拆。
3. **行动清单必须是动作。** "注意""重视""关注""思考"不算动作。
4. **批判必须有论据。** 说"这有盲点"必须附上"为什么这是一个盲点"和"这个盲点的后果是什么"。
5. **案例必须有可迁移点。** 案例不只是故事，是能搬走用的东西。
6. **不照抄原文。** 笔记是你和内容的对话记录，不是内容的压缩版。
7. **反翻译腔。** 白话写，读出声不卡再交付。
8. **全篇禁用表格。** flomo 渲染不了 markdown 表格。所有表格换成层级结构——加粗标题 + 缩进列表。对比类内容用分段 + `---` 分隔，不用 `|` 分隔符。
