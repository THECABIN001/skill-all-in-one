# 金融—红利 ETF 买卖检测 · 纯估值版

> 从 v3.0 完整框架中剥离估值因子簇 V，独立为轻量级估值温度计。不涉及基本面质量 Q、趋势反转 T、拥挤流动性 L 及结构性否决，**仅回答一个问题：现在有多便宜（或多贵）。**
>
> **研究用途，不构成投资建议。**

## 2. 估值因子 V 的计算公式

### 2.1 三步走

```text
第一步：三个便宜度
  PE便宜度   = 100 - PE分位（10年或5年，按窗口选择）
  PB便宜度   = 100 - PB分位
  股息率便宜度 = 股息率分位

第二步：股息率经股债息差校正
  息差      = 静态股息率 - 10年期国债收益率
  息差Z     = (当前息差 - 过去4年滚动均值) / 过去4年滚动标准差
  息差映射分 = clamp(50 + 25 × 息差Z, 0, 100)
  有效股息吸引力 = min(股息率便宜度, 息差映射分)

第三步：合成 V
  V = 30% × PE便宜度 + 30% × PB便宜度 + 40% × 有效股息吸引力
```

### 2.2 温度

```text
温度 = 100 - V
```

温度范围 0–100：**越低越便宜，越高越贵。**

### 2.3 双窗口规则

与 v3.0 一致：同时计算 10 年和 5 年窗口的温度：

| 窗口 | 用途 |
|---|---|
| 10 年温度 | 主判断基准 |
| 5 年温度 | 辅助验证 |

**背离处理：** 同一指数的 10 年与 5 年温度差异 **> 15°C** → 标注 `⚠️ 温度背离`，以 10 年为准但操作建议降一级（更保守）。

**历史不足 5 年时**：该指标数据质量最高为 C，5 年温度仅供参考，不据此操作。

## 3. 背景知识：公式中的关键概念

### 3.1 clamp —— 防溢出

`clamp(x, 下界, 上界)` 把 x 限制在上下界之间：

```text
clamp(75, 0, 100)  = 75   ← 在界内，原样
clamp(-30, 0, 100) = 0    ← 低于下界，截断
clamp(140, 0, 100) = 100  ← 高于上界，截断
```

### 3.2 息差 Z —— 当前息差在历史上的位置

```text
息差Z = (当前息差 - 过去4年滚动均值) / 过去4年滚动标准差
```

| Z 值 | 含义 |
|---|---:|
| Z = 0 | 息差等于均值，不便宜不贵 |
| Z = +1 | 息差高 1σ，红利相对债券有吸引力 |
| Z = +2 | 息差高 2σ，红利极度有吸引力 |
| Z = -1 | 息差低 1σ，债券相对更有吸引力 |

**映射到 0–100 分：**

```text
息差映射分 = clamp(50 + 25 × 息差Z, 0, 100)
```

50 是锚（Z=0 → 50 分），25 是敏感度（Z 每变 1σ → 分数变 25 分）。±2σ 刚好触达 0 和 100。

### 3.3 取 min() —— 两关都过才算便宜

```text
有效股息吸引力 = min(股息率便宜度, 息差映射分)
```

**设计意图：** 股息率本身的历史位置（便宜度）和相对债券的吸引力（息差映射分），两者必须同时成立。任一个说"不贵"，就不能打高分。

| 场景 | 股息率便宜度 | 息差映射分 | min | 若取均值 |
|---|---|---|---|---|
| 股息率历史上很贵（20），但国债更低所以息差诱人（95） | 20 | 95 | **20**（抑制虚假便宜） | 57.5 |
| 股息率历史上很便宜（90），但国债飙升息差消失（10） | 90 | 10 | **10**（防御债券替代） | 50 |

## 4. 温度区间与操作建议

| 温度 | V 对应 | 含义 | 买入操作 | 卖出操作 |
|---|---:|---:|:---:|---|---|
| **< 20°C** | > 80 | 🔵 极度低估 | 🟣 重仓区：子弹全出，分 2–3 批 | — |
| **20–35°C** | 65–80 | 🟢 显著低估 | 🟢 加大区：定投翻倍，动用子弹仓 1/3 | — |
| **35–50°C** | 50–65 | 🔵 偏低 | 🔵 行动区：准备资金，每周检查 | — |
| **50–65°C** | 35–50 | ⚪ 合理偏低 | 正常定投，不增不减 | 🟢 安全持有 |
| **65–80°C** | 20–35 | 🟡 合理偏高 | 暂停新增买入 | 🟢 安全持有 |
| **80–90°C** | 10–20 | 🟠 偏贵 | — | 🟡 关注区：停止定投，持有观望 |
| **90–95°C** | 5–10 | 🔴 显著偏贵 | — | 🟠 减仓区：按梯度分批减仓 |
| **> 95°C** | < 5 | 🔴 极度昂贵 | — | 🔴 清仓区边缘：加速减仓或清仓 |

> **注意：** 以上为纯估值维度的操作建议。完整框架中还需综合基本面质量、趋势反转、拥挤流动性和结构性否决。本温度计仅回答"估值维度的便宜程度"，最终操作应结合完整 v3.0 检测报告判断。

## 5. 温度区间边界值的含义

以 10 年窗口为例，各温度阈值的近似含义：

| 温度阈值 | 估值组合（近 10 年）大致对应 |
|---|---|
| **20°C** | PE ≈ 6.0（8%分位），PB ≈ 0.65（5%分位），股息率 ≈ 7%（85%分位），息差极大 |
| **35°C** | PE ≈ 6.5（15%分位），PB ≈ 0.70（15%分位），股息率 ≈ 6.5%（70%分位），息差大 |
| **50°C** | PE ≈ 7.4（50%分位），PB ≈ 0.78（35%分位），股息率 ≈ 5.3%（50%分位），息差中性 |
| **65°C** | PE ≈ 8.3（70%分位），PB ≈ 0.85（55%分位），股息率 ≈ 4.5%（30%分位），息差偏低 |
| **80°C** | PE ≈ 9.5（85%分位），PB ≈ 0.95（75%分位），股息率 ≈ 3.8%（15%分位），息差低 |

## 6. 与 v2 温度计的区别

| | v2 温度计（旧） | v3.0 纯估值版（新） |
|---|---|---|
| **公式** | 20%×PE分位 + 40%×PB分位 + 40%×(1-股息率分位) | V = 30%×PE便宜度 + 30%×PB便宜度 + 40%×有效股息吸引力；温度=100-V |
| **PE 权重** | 20% | 30%（提升，PE 区分度高于 PB） |
| **PB 权重** | 40% | 30%（下调，PB 在 0.7-0.9 窄幅波动，原权重过高） |
| **股息率处理** | 裸分位线性加入 | 经息差 Z 校正 + min() 交叉验证 |
| **债券影响** | 不计入温度公式 | 通过息差 Z 间接校正（不单独计票） |
| **防重复放大** | 无 | min() 结构抑制"低利率虚假便宜" |

## 10. 计算示例（2026-07-23，中证红利 10 年窗口）

```text
已知：
  PE = 7.98，PE 10年分位 = 68%
  PB = 0.78，PB 10年分位 = 40%
  静态股息率 = 4.83%，股息率 10年分位 = 42%
  10年国债 = 1.74%
  息差 4年均值 ≈ 2.8%，标准差 ≈ 0.9%

计算：
  PE便宜度 = 100 - 68 = 32.0
  PB便宜度 = 100 - 40 = 60.0
  股息率便宜度 = 42.0
  息差 = 4.83 - 1.74 = 3.09%
  息差Z = (3.09 - 2.80) / 0.90 = 0.32
  息差映射分 = clamp(50 + 25×0.32, 0, 100) = 58.0
  有效股息吸引力 = min(42.0, 58.0) = 42.0
  V = 0.30×32.0 + 0.30×60.0 + 0.40×42.0 = 9.6 + 18.0 + 16.8 = 44.4
  温度 = 100 - 44.4 = 55.6°C

判定：55.6°C → ⚪ 合理偏低区间（50–65°C）
操作：正常定投，不增不减；🟢 安全持有
```
